Adapter 接口定义

// Axios 适配器接口 — 接收 config，返回 Promise function adapter(config) { // config 已完成合并、转换器、拦截器预处理 // 返回 Promise，resolve 时触发 response 转换器 return new Promise(function(resolve, reject) { // 执行实际请求... const response = { data: responseData, status: request.status, statusText: request.statusText, headers: responseHeaders, config: config, request: request }; // settle 决定 resolve 或 reject settle(resolve, reject, response); }); }

XHR Adapter 请求流程（浏览器环境）

1. dispatchRequest(config)

Axios 核心模块，合并默认配置与应用配置，运行请求转换器。

2. getAdapter() 选择适配器

根据环境判断：浏览器 → xhrAdapter，Node → httpAdapter。可通过 config.adapter 手动指定。

3. xhrAdapter(config) 创建 Promise

返回 Promise，异步执行 XMLHttpRequest。

4. XMLHttpRequest.open()

request.open(method, url, async) 建立连接。

5. 设置请求头与选项

setRequestHeader 设置自定义头，withCredentials 处理跨域 Cookie，responseType 指定响应格式。

6. 注册事件处理器

onloadend / onreadystatechange：响应完成；onabort：取消；onerror：网络错误；ontimeout：超时。

7. request.send(data)

发送请求，data 为请求体（FormData / JSON / 二进制）。

8. settle(resolve, reject, response)

根据 HTTP 状态码决定 Promise resolve 或 reject。2xx → resolve，其他 → reject。

9. Response Interceptors

响应拦截器处理 data 转换、错误标准化等。

HTTP Adapter 请求流程（Node 环境）

1. buildFullPath() 构建完整路径

合并 baseURL + url，处理绝对/相对路径。

2. 数据流处理

Buffer / ArrayBuffer / string → Buffer；FormData → stream；File/Blob → stream。

3. http/https.request(options)

创建 Node.js http(s) 请求，支持代理、重定向、超时。

4. 进度与取消

通过 EventEmitter 实现 abort 信号，可配合 AbortController 使用。

自定义 Mock 适配器

// mock-adapter.js — 模拟请求适配器 function mockAdapter(config) { return new Promise((resolve, reject) => { // 模拟延迟 setTimeout(() => { const response = { data: { message: 'Mock 响应', config }, status: 200, statusText: 'OK', headers: { 'content-type': 'application/json' }, config, request: null }; // 模拟错误（config.forceError = true） if (config.forceError) { return reject(new Error('Mock Error')); } resolve(response); }, config.delay || 500); }); } // 使用方式 const axios = require('axios'); axios.defaults.adapter = mockAdapter;

实战：自定义适配器实现请求重试

function retryAdapter(config) { const maxRetries = config.retryCount || 3; const retryDelay = config.retryDelay || 1000; const originalAdapter = require('axios/lib/adapters/xhr'); function attempt(retryCount) { return originalAdapter(config) .catch(err => { if (retryCount < maxRetries && isRetryableError(err)) { return new Promise(resolve => setTimeout(() => resolve(attempt(retryCount + 1)), retryDelay )); } throw err; }); } return attempt(0); } // 使用 axios.defaults.adapter = retryAdapter;

Adapter vs Interceptor vs Transform

机制作用层级执行时机适用场景
Adapter 底层网络 最终请求发送 跨平台适配、Mock、调试拦截
Interceptor 请求/响应 请求前/响应后 统一 header、错误处理、日志
Transform 数据转换 请求序列化/响应反序列化 JSON 解析、格式转换

为什么需要适配器？

同一套 API，多端运行

Axios 代码可以在浏览器 (XMLHttpRequest)、Node.js (http 模块)、微信小程序、React Native 等环境运行，底层自动切换适配器。

可测试性

通过 Mock 适配器，测试套件无需启动真实服务器，可模拟任意响应（成功/错误/超时）。

功能扩展

请求重试、自动降级、调试拦截等横切关注点可通过自定义适配器统一注入。
