🔗 SharedArrayBuffer 共享内存示例

原理：SharedArrayBuffer 允许多个线程共享同一块内存，无需拷贝。 使用 Atomics API 保证原子性操作，避免竞态条件。
⚠️ 安全要求：SharedArrayBuffer 需要 Cross-Origin-Isolation。 访问此页面需要服务器设置以下响应头：
Cross-Origin-Embedder-Policy: require-corp
Cross-Origin-Opener-Policy: same-origin

使用 Node.js 运行：node server.js，然后访问 https://localhost:8443
