CDN 工作原理

🌍 用户请求 → 访问者
🌍 Cloudflare Edge → 全球 200+ 节点
🏠 源站服务器 ← 返回内容 + 缓存

原理：用户请求先到最近 Edge 节点 → 命中缓存直接返回 → 未命中则回源获取 → 返回同时缓存到 Edge

快速上手 5 步走

Step 1: 注册账号

访问 cloudflare.com，使用邮箱注册账号。

Step 2: 添加网站

点击 "Add a Site"，输入域名（如 example.com），Cloudflare 会自动扫描现有 DNS 记录。

Step 3: 修改 Nameservers

在域名注册商（阿里云/腾讯云/GoDaddy 等）处，将 NS 记录改为 Cloudflare 提供地址：

主 NS: main.ns.cloudflare.com
副 NS: secondary.ns.cloudflare.com

⏱️ 生效时间：几分钟到 48 小时不等

Step 4: 配置 DNS + CDN

在 Cloudflare Dashboard 中配置 DNS 记录，状态选择：

状态图标效果
DNS Only☁️ 灰色仅 DNS，不走 CDN
Proxied☁️ 橙色流量经过 Cloudflare（推荐）

Step 5: 配置 SSL

推荐使用 Full (strict) 模式：

SSL/TLS → Overview → Full (strict)

DNS 传播验证

使用 dig 命令验证不同 DNS 服务器的解析结果：

# Cloudflare DNS
dig @1.1.1.1 example.com

# Google DNS
dig @8.8.8.8 example.com

# 本地 ISP DNS
dig @dns.isp.com example.com

HTTPS 重定向

Cloudflare 可以强制 HTTP 请求跳转到 HTTPS：

# 在 SSL/TLS → Edge Certificates 中启用
Always Use HTTPS: ON

# 或使用 Page Rules（已弃用）
Rule: http://*example.com/*
Action: Always Use HTTPS

缓存机制

Cloudflare 自动缓存静态资源：图片、CSS、JS、字体等。

缓存级别

级别说明
Bypass不缓存，直接回源
No Query String忽略查询字符串缓存
Standard标准缓存（默认）
Cache Everything缓存所有，包括动态内容

手动清理缓存

# Dashboard: Caching → Configuration → Purge Everything

# API 方式
curl -X POST "https://api.cloudflare.com/client/v4/zones/{zone_id}/purge_cache" \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"purge_everything": true}'

Cache-Control 响应头

指令说明
Cache-Control: max-age=3600资源缓存 1 小时
Cache-Control: no-cache每次都验证
Cache-Control: no-store不缓存
Cache-Control: public可被缓存
Cache-Control: private仅浏览器缓存

Always Online

当源站宕机时，Cloudflare 可以显示缓存的旧内容：

Caching → Configuration → Always Online: ON
