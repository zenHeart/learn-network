七牛云服务详解

说明：本页面为七牛云服务学习演示。实际使用需要配置 accessKey、secretKey 和 bucket。 本示例为模拟演示，实际运行需要服务端提供 upload token。

1. 七牛云概述

服务类型 说明 适用场景
融合 CDN 全球内容分发加速 静态资源、下载分发
对象存储 (Kodo) 海量非结构化数据存储 图片、视频、文件存储
图片处理 缩放、裁剪、格式转换 图床、相册、媒体
多媒体服务 直播、点播、转码 在线教育、直播平台

2. 上传流程

客户端
请求上传 Token
→
业务服务器
生成 Token
→
客户端
上传到七牛云
→
七牛云
返回 Key
⚠️ 安全提示：不要在前端暴露 SecretKey！ 必须通过业务服务器生成 upload token。

4. 图片处理示例

处理类型 URL 参数 示例
缩放 ?imageMogr2/thumbnail/!200x200 等比缩放最大 200x200
裁剪 ?imageMogr2/crop/300x300 裁剪 300x300
格式转换 ?format=webp 转换为 WebP
质量优化 ?imageslim 无损压缩
水印 ?watermark/... 图片水印
URL 组合示例：
https://domain.com/photo.jpg?imageMogr2/thumbnail/800x600/smooth/50/format/webp

5. CDN 刷新与预取

操作 说明 适用场景
URL 刷新 清除指定 URL 的缓存 更新已发布的资源
目录刷新 刷新目录下所有资源 批量更新
URL 预取 提前拉取资源到 CDN 节点 大文件发布前

6. 防盗链策略

类型 实现方式 安全性
Referer 白名单 配置允许的域名列表 中等
时间戳签名 URL 携带过期时间和签名 较高
IP 白名单 限制访问 IP 高
