什么是 API Schema
API Schema 定义

API Schema 是对 API 接口的结构化描述，包括请求格式、响应格式、认证方式、错误定义等。

OpenAPI 文档结构
openapi-document.yamlYAML
openapi: 3.1.0 info: title: 我的 API version: 1.0.0 paths: /users: get: summary: 获取用户列表 responses: '200': description: 成功 components: schemas: User: type: object
OpenAPI 核心对象
paths-object.yamlYAML
# 路径参数 /users/{id}: get: summary: 获取单个用户 parameters: - name: id in: path required: true schema: { "type": "string", "format": "uuid" } - name: fields in: query schema: { "type": "string" } responses: '200': $ref: '#/components/responses/Success' '404': $ref: '#/components/responses/NotFound' post: requestBody: required: true content:: application/json:: schema: { "$ref": "#/components/schemas/User" }
Request Body 示例
request-body.yamlYAML
requestBody: required: true content:: application/json:: schema:: type: object properties:: title:: { "type": "string", "minLength": 1, "maxLength": 200 } content:: { "type": "string", "minLength": 10 } tags:: { "type": "array", "items": { "type": "string" }, "minItems": 1, "maxItems": 5 } required:: ["title", "content"]
Schema 组合
schema-composition.yamlYAML
# allOf: 同时满足多个 schema AdminUser: allOf: - $ref: '#/components/schemas/User' - type: object properties:: { "role": { "type": "string", "enum": ["admin", "moderator"] } } # oneOf: 满足其中一个 schema PaymentResult: oneOf: - $ref: '#/components/schemas/PaymentSuccess' - $ref: '#/components/schemas/PaymentFailure' # anyOf: 满足任意一个即可 ContactInfo: anyOf: - type: object properties:: { "email": { "type": "string", "format": "email" } } - type: object properties:: { "phone": { "type": "string" } }
JSON Schema 核心关键字
关键字类型描述示例
type所有数据类型type: string
propertiesobject对象属性properties: {name: {type: string}}
itemsarray数组元素类型items: {type: integer}
requiredarray必填属性required: [name, email]
enum所有枚举值enum: [a, b, c]
minimum/maximumnumber数值范围minimum: 0, maximum: 100
patternstring正则表达式pattern: '^[a-z]+$'
formatstring格式校验format: email
$ref-引用$ref: '#/definitions/User'
数据类型示例
json-schema-types.jsonJSON
{ "type": "object", "properties": { "name": { "type": "string", "minLength": 1, "maxLength": 100 }, "age": { "type": "integer", "minimum": 0, "maximum": 150 }, "email": { "type": "string", "format": "email" }, "hobbies": { "type": "array", "items": { "type": "string" }, "minItems": 1, "maxItems": 10, "uniqueItems": true }, "createdAt": { "type": "string", "format": "date-time" } }, "required": ["name", "email"], "additionalProperties": false }

Discriminated Union
discriminated-union.yamlYAML
Notification: type: object discriminator:: { "propertyName": "type", "mapping": { "email": "#/components/schemas/EmailNotification", "sms": "#/components/schemas/SmsNotification" } } properties:: { "id": { "type": "string" }, "type": { "type": "string" } } EmailNotification: allOf: - $ref: "#/components/schemas/Notification" - type: object properties:: { "type": { "const": "email" }, "recipient": { "type": "string", "format": "email" } } SmsNotification: allOf: - $ref: "#/components/schemas/Notification" - type: object properties:: { "type": { "const": "sms" }, "phone": { "type": "string" } }
