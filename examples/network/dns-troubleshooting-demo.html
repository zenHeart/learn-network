常见问题场景

场景 1：域名解析失败（NXDOMAIN）

$ dig example.com

;; ->>HEADER<<- opcode: QUERY, status: NXDOMAIN, id: 12345

可能原因：
1. 域名未注册或过期
2. 域名拼写错误
3. DNS 服务器配置错误

排查命令：
whois example.com  # 检查域名状态
dig @ns1.example.com example.com  # 查询权威 DNS

场景 2：DNS 污染/劫持

$ dig example.com +short
203.0.113.1  # 返回了错误的 IP！

可能原因：
1. ISP DNS 劫持
2. /etc/hosts 被篡改
3. DNS 缓存中毒

排查命令：
cat /etc/hosts | grep example  # 检查 hosts 文件
dig @1.1.1.1 example.com  # 对比 Cloudflare DNS
dig @8.8.8.8 example.com  # 对比 Google DNS

场景 3：解析缓慢

$ dig example.com +stats

;; Query time: 2500 msec  # 太慢了！

可能原因：
1. DNS 服务器响应慢
2. 网络延迟高
3. CNAME 链过长

排查命令：
time dig @1.1.1.1 example.com  # 测试不同 DNS
dig example.com +trace  # 追踪完整路径

DNS 记录类型对比

类型名称用途示例
A 地址记录 域名 → IPv4 example.com → 93.184.216.34
AAAA IPv6 地址 域名 → IPv6 example.com → 2606:2800:220:1::
CNAME 别名记录 域名 → 另一个域名 www.example.com → example.com
MX 邮件交换 邮件服务器地址 example.com → mail.example.com (优先级 10)
TXT 文本记录 SPF、验证等 v=spf1 include:_spf.example.com ~all
NS 域名服务器 域名由谁解析 example.com → ns1.example.com
SOA 起始授权 区域管理信息 serial: 2026032601, refresh: 3600
PTR 指针记录 IP → 域名（反向） 8.8.8.8 → dns.google

查询示例

# A 记录（最常用）
$ dig example.com A +short
93.184.216.34

# AAAA 记录（IPv6）
$ dig example.com AAAA +short
2606:2800:220:1:2470:3c:2e:46

# MX 记录（邮件）
$ dig example.com MX +short
0 mail.example.com.

# CNAME 记录（别名）
$ dig www.example.com CNAME +short
example.com.

# TXT 记录（SPF 等）
$ dig example.com TXT +short
"v=spf1 -all"

# NS 记录（域名服务器）
$ dig example.com NS +short
a.iana-servers.net.
b.iana-servers.net.

# 反向查询（PTR）
$ dig -x 8.8.8.8 +short
dns.google.

dig 命令速查

# 基础查询
$ dig example.com                  # 查询 A 记录
$ dig @8.8.8.8 example.com         # 指定 DNS 服务器
$ dig example.com AAAA            # 查询 IPv6

# 输出控制
$ dig +short example.com           # 只显示结果
$ dig +noall +answer              # 只显示答案
$ dig +stats example.com          # 显示统计
$ dig +trace example.com           # 追踪完整路径
$ dig +tcp example.com            # 强制 TCP

# 反向查询
$ dig -x 8.8.8.8                  # PTR 记录

nslookup 命令速查

# 基础查询
$ nslookup example.com            # 查询 A 记录
$ nslookup example.com 8.8.8.8   # 指定 DNS
$ nslookup -type=MX example.com   # 查询 MX

# Windows 特定
$ ipconfig /displaydns            # 显示 DNS 缓存
$ ipconfig /flushdns             # 清除 DNS 缓存

# 交互模式
$ nslookup
> set type=A
> example.com
> set type=MX
> example.com
> exit

清除缓存命令

系统命令
Windows ipconfig /flushdns
macOS sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
Linux (systemd) sudo systemd-resolve --flush-caches
Linux (dnsmasq) sudo systemctl restart dnsmasq
Chrome 访问 chrome://net-internals/#dns → Clear host cache
