pushState vs replaceState vs popstate 区别

pushState()
添加新历史记录
→ 后退可回到上一条
→ 不触发 popstate
replaceState()
替换当前记录
→ 后退跳过当前
→ 不触发 popstate
back() / forward() / go()
浏览器前进/后退
→ 触发 popstate 事件
→ JS 可读取 event.state
