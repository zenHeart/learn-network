私有 IP 地址范围

A 类 - 大型组织

范围：10.0.0.0 - 10.255.255.255

CIDR：10.0.0.0/8

可用主机：16,777,214

常见用途：AWS VPC、阿里云、企业骨干网

B 类 - 中型网络

范围：172.16.0.0 - 172.31.255.255

CIDR：172.16.0.0/12

可用主机：1,048,576

常见用途：Docker 默认网段、VMware

C 类 - 小型网络

范围：192.168.0.0 - 192.168.255.255

CIDR：192.168.0.0/16

可用主机：65,536

常见用途：家庭路由器、小型办公室

IPv4 vs IPv6 对比

IPv4

长度：32 位（4 字节）

格式：192.168.1.1

地址数量：约 43 亿

子网掩码：255.255.255.0 或 /24

IPv6

长度：128 位（16 字节）

格式：2001:db8::1

地址数量：约 340 润

仅用 CIDR 表示法
