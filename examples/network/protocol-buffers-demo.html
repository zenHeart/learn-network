什么是 Protocol Buffers？

核心定义

Protocol Buffers（Protobuf）是 Google 开发的一种语言无关、平台无关的结构化数据序列化协议。它使用二进制格式，比 JSON 更小、更快。

JavaScript 使用演示

基础编码/解码

点击按钮开始演示...

使用 protobufjs 库

// 1. 安装
// npm install protobufjs

// 2. 加载 .proto 文件
const protobuf = require('protobufjs');
const root = await protobuf.load('person.proto');
const Person = root.lookupType('Person');

// 3. 编码
const message = Person.create({
  name: '张三',
  id: 12345,
  email: 'zhangsan@example.com'
});
const buffer = Person.encode(message).finish();

// 4. 解码
const decoded = Person.decode(buffer);
console.log(decoded);
// { name: '张三', id: 12345, email: 'zhangsan@example.com' }

常见错误处理

// 验证（编码前自动验证）
try {
  const message = Person.create({ name: '张三' });
  Person.verify(message);  // 返回错误信息或 null
} catch (e) {
  console.error('验证失败:', e.message);
}

// .required 字段检查
const err = Person.verify({ id: 123 }); // name 是必需字段
if (err) console.error(err);

步骤 1: 定义 .proto 文件

// person.proto
syntax = "proto3";

package myapp;

message Person {
  string name = 1;
  int32 id = 2;
  string email = 3;

  enum PhoneType {
    MOBILE = 0;
    HOME = 1;
    WORK = 2;
  }

  message Phone {
    string number = 1;
    PhoneType type = 2;
  }

  repeated Phone phones = 4;
}

步骤 2 & 3: 安装 protoc 并编译

安装 protoc 编译器

# macOS
brew install protobuf

# Ubuntu/Debian
sudo apt install protobuf-compiler

# Windows (使用 chocolatey)
choco install protobuf

编译为各语言

# JavaScript (需要 @com_category_js 插件)
protoc --js_out=import_style=commonjs,binary:. person.proto

# Python
protoc --python_out=. person.proto

# Java
protoc --java_out=. person.proto

# Go
protoc --go_out=. person.proto

# 所有语言（一次生成）
protoc --js_out=. --python_out=. --java_out=. --go_out=. person.proto

步骤 4: 应用中使用

// JavaScript 中使用
const protobuf = require('protobufjs');
const root = protobuf.loadSync('person_pb.js');

// 获取类型
const Person = root.lookupType('myapp.Person');

// 编码
const msg = Person.create({ name: '张三', id: 1, email: 'test@example.com' });
const bytes = Person.encode(msg).finish();

// 解码
const decoded = Person.decode(bytes);
console.log(decoded);

Proto 文件最佳实践

  • 使用 proto3 语法（最新版本）
  • 频繁字段使用 1~15 编号（更省空间）
  • 不要删除或重用字段编号
  • 使用 package 避免命名冲突
  • 为枚举定义零值（默认选项）
  • 使用 repeated 而非数组包装类型

Protocol Buffers vs JSON 对比

📦 体积

JSON较大
Protobuf小 30%~70%

⚡ 速度

JSON 解析基准
Protobuf 解析快 5~10x

🛡️ 类型安全

弱类型 强类型

Protobuf 通过 .proto 定义提供编译时类型检查

🔍 可读性

JSON 高 Protobuf 低

调试时 JSON 更方便阅读，Protobuf 需解码

选择指南

场景 推荐 原因
HTTP API（浏览器） JSON 原生支持，无需额外解析
gRPC 服务间通信 Protobuf 高性能，二进制更高效
数据持久化 Protobuf 更小存储空间，更快读写
开放 API（公开） JSON 更广泛的客户端支持
大型数据集 Protobuf 显著节省带宽和存储

0A 05 E5 BC A0 E4 BA BA  // name="张三"
10 B9 60        // id=12345
1A 14 7A 68 61... // email
2A 12 0A 0B 31 33 38... // phones
