gRPC vs REST 对比

🔵 gRPC

  • ✓ HTTP/2 多路复用
  • ✓ Protobuf 二进制序列化
  • ✓ 双向流式支持
  • ✓ 原生代码生成
  • ✓ 强类型 .proto 定义
  • ✗ 浏览器需 grpc-web
  • ✗ 调试需解码工具
VS

🟢 REST

  • ✓ 浏览器原生支持
  • ✓ 人类可读 JSON
  • ✓ 生态丰富
  • ✓ 简单易上手
  • ✓ 广泛认知度
  • ✗ JSON 体积大
  • ✗ 无原生流支持

📋 选型决策树

需要浏览器直接调用？ → 是 → REST
微服务间高性能通信？ → 是 → gRPC
需要双向流式传输？ → 是 → gRPC
团队快速交付优先？ → 是 → REST
严格企业规范要求？ → 是 → SOAP
