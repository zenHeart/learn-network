排查决策树
1. 浏览器报证书错误？
  |- 是 → DevTools → Security 面板 查看证书详情和路径
  |- "证书已过期" → 检查有效期 → 续期证书
  |- "无法验证身份" → 检查证书链 → 补全中间证书
  |- "域名不匹配" → 检查 SAN/CN → 重新申请
  |- "不受信任" → 检查根 CA → 自签名? 导入根证书
  |- 控制台混合内容警告 → 检查资源 URL → 改用 HTTPS
  |- 仍无法确定 → openssl s_client -connect site:443 -showcerts
      → 使用 SSL Labs 做全面检测
快速修复命令
检查证书有效期
$ openssl x509 -in server.crt -noout -dates
notBefore=Jun 1 00:00:00 2024 GMT notAfter=Jun 1 00:00:00 2025 GMT
检查证书支持的域名
$ openssl x509 -in server.crt -noout -ext subjectAltName
X509v3 Subject Alternative Name: DNS:example.com, DNS:www.example.com
连接服务器检查证书链
$ openssl s_client -connect example.com:443 -showcerts
Verify return code: 0 (ok)
验证完整证书链
$ openssl verify -CAfile root.crt -untrusted int.crt server.crt
server.crt: OK
