5. SSL Labs 安全评级

📊 评级标准

了解 SSL Labs 如何评估 SSL/TLS 配置的安全性

A
协议配置 TLS 1.3 ✓
密钥交换 安全 ✓
加密算法 AES-256-GCM ✓

评分等级说明

A 卓越 - 完全符合最佳实践
B 良好 - 有轻微配置问题
C 一般 - 存在中等风险问题
D 较差 - 存在严重安全隐患
F 失败 - 配置极不安全或存在漏洞

影响评分的因素：

  • 协议版本（SSL 3.0、TLS 1.0/1.1 降低评分）
  • 证书密钥长度（小于 2048 位降低评分）
  • 密码套件强度（弱加密降低评分）
  • 证书链完整性（不完整降低评分）
  • 支持前向保密（不支持降低评分）
  • 已知漏洞（如 POODLE、Heartbleed 等）
