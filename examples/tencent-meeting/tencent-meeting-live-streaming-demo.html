腾讯会议直播技术概览

产品体系

腾讯会议提供完整的视频会议和直播解决方案，主要包括：

  • 腾讯会议 SaaS - 企业级视频会议平台
  • TRTC SDK - 实时音视频通信（基于 WebRTC）
  • CSS 直播服务 - 大规模直播分发（RTMP/HLS）
  • 会议 API - 开放接口，支持企业定制

SFU vs MCU

维度 SFU MCU
架构 转发而不混合 混合后转发
延时 更低 (<200ms) 较高 (300-500ms)
带宽 发送 N 路，接收 M 路 发送 1 路，接收 1 路
适用 互动场景 会议录制

直播协议对比

协议 延时 场景 兼容性
UDP/QUIC <200ms 实时通话 需 TRTC SDK
RTMP 2-5s 直播推流 最佳
HTTP-FLV 2-5s 直播观看 需播放器
HLS 5-10s 移动端 最佳
DASH 5-10s 国际分发 一般

协议选择建议

🎯 根据场景选择协议
  • 低延时互动（连麦、会议）→ UDP/QUIC + TRTC SDK
  • 标准直播（发布会、教育）→ RTMP 推流 + HLS 观看
  • 移动端为主 → HLS（iOS/Android 原生支持）
  • 极致低延时 → WebRTC 或私有 QUIC

代码示例

TRTC 初始化与加入房间

import TRTC from 'trtc-sdk-js';

// 1. 创建 TRTC 实例
const trtc = TRTC.create({
  sdkAppId: 1400000000,  // 替换为你的 SDKAppId
  userId: 'user_' + Date.now(),
  userSig: 'xxxxx'        // 后端生成
});

// 2. 加入房间
await trtc.enterRoom({
  roomId: 123456
});

// 3. 开启本地视频
await trtc.startLocalVideo({
  view: document.getElementById('local-video')
});

// 4. 开启本地音频
await trtc.startLocalAudio();

观众观看直播流

// 观众端：订阅远端流
trtc.on(TRTC.EVENT.REMOTE_VIDEO_AVAILABLE, ({ userId }) => {
  // 远端用户开启视频
  trtc.startRemoteVideo({
    userId: userId,
    view: document.getElementById('remote-video')
  });
});

trtc.on(TRTC.EVENT.REMOTE_AUDIO_AVAILABLE, ({ userId }) => {
  // 远端用户开启音频
  trtc.startRemoteAudio({ userId });
});

// 监听用户进入/离开
trtc.on(TRTC.EVENT.REMOTE_USER_ENTER, (userId) => {
  console.log('用户加入:', userId);
});

trtc.on(TRTC.EVENT.REMOTE_USER_LEAVE, (userId) => {
  console.log('用户离开:', userId);
});

网络质量监控

// 监听网络质量变化
trtc.on(TRTC.EVENT.NETWORK_QUALITY, (networkQuality) => {
  const { userId, level } = networkQuality;
  // level: 0-6, 0=最好, 6=最差
  
  const qualityMap = {
    0: '极好',
    1: '很好',
    2: '好',
    3: '中等',
    4: '差',
    5: '很差',
    6: '不可用'
  };
  
  console.log(`用户 ${userId} 网络质量: ${qualityMap[level]}`);
  
  if (level > 4) {
    showWarning('您的网络质量较差');
  }
});

// 监听音量
trtc.on(TRTC.EVENT.AUDIO_VOLUME, ({ userId, volume }) => {
  // volume: 0-100
  if (volume > 0) {
    console.log(`用户 ${userId} 在说话，音量 ${volume}`);
  }
});

腾讯会议直播开发清单

开发腾讯会议直播应用时，需要检查以下关键点：

  • 1. SDK 接入配置
    完成 TRTC SDK 或腾讯会议 SDK 的引入和初始化配置
  • 2. UserSig 后端生成
    UserSig 必须在后端生成，禁止在前端暴露 secret
  • 3. 房间号管理
    设计合理的房间号生成和分配策略
  • 4. 权限控制
    区分主播/观众/管理员权限，实现细粒度控制
  • 5. 网络质量监控
    实现网络质量反馈和降级策略
  • 6. CDN 直播配置
    配置直播推流地址和 CDN 分发策略
  • 7. 异常处理
    处理断网、设备切换、页面刷新等异常场景
  • 8. 移动端适配
    HLS 协议支持、App 保活、后台播放
  • 9. 性能优化
    码率自适应、关键帧间隔、视频分辨率选择
  • 10. 数据统计
    接入会议数据埋点和质量监控
