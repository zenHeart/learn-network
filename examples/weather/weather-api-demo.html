天气 API 学习演示 - wttr.in vs OpenWeather

wttr.in 免费天气 API 免费

无需注册，直接使用。适合快速原型和学习演示。

请求代码

// wttr.in JSON 请求
const response = await fetch('https://wttr.in/Beijing?format=j1&m');
const data = await response.json();

// 提取当前天气
const current = data.current_condition[0];
const weather = {
  temp: parseInt(current.temp_C),
  condition: current.weatherDesc[0].value,
  humidity: current.humidity
};

API 参数

参数 说明 示例
format=j1 JSON 格式输出 ?format=j1
m 公制单位 ?format=j1&m
lang=zh 中文语言 ?lang=zh
1, 2, 3 预报天数 ?3

OpenWeather API 需 API Key

专业天气数据，高精度。需要注册获取 API Key。

请求代码

// OpenWeather API 请求
const apiKey = 'YOUR_API_KEY';
const city = 'Beijing,CN';

const url = `https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${apiKey}&units=metric&lang=zh_cn`;

const response = await fetch(url);
const data = await response.json();

// 提取天气数据
const weather = {
  temp: data.main.temp,
  condition: data.weather[0].main,
  humidity: data.main.humidity,
  description: data.weather[0].description
};

获取 API Key

  1. 访问 openweathermap.org/api
  2. 注册账户（或登录）
  3. 进入 "API Keys" 页面
  4. 复制默认 Key 或创建新 Key

WeatherData 通用类型

interface WeatherData {
  location: string;        // 位置名称
  temp: number;            // 温度（摄氏度）
  feelsLike: number;       // 体感温度
  humidity: number;        // 湿度百分比
  windSpeed: number;       // 风速 (km/h)
  windDir: string;         // 风向
  condition: string;       // 天气状况
  uvIndex: number;          // 紫外线指数
  visibility: number;       // 能见度 (km)
  pressure: number;       // 气压 (hPa)
  precipitation: number;   // 降水量 (mm)
}

wttr.in 响应类型

interface WttrResponse {
  current_condition: WttrCurrent[];
  nearest_area: WttrArea[];
  weather: WttrForecast[];
}

interface WttrCurrent {
  temp_C: string;
  FeelsLike: string;
  humidity: string;
  windspeedKmph: string;
  winddir16Point: string;
  weatherDesc: { value: string }[];
  uvIndex: string;
  visibility: string;
  pressure: string;
  precipMM: string;
}

interface WttrArea {
  areaName: { value: string }[];
  country: { value: string }[];
  region: { value: string }[];
  latitude: string;
  longitude: string;
}

OpenWeather 响应类型

interface OpenWeatherResponse {
  coord: { lon: number; lat: number };
  weather: {
    id: number;
    main: string;
    description: string;
    icon: string;
  }[];
  main: {
    temp: number;
    feels_like: number;
    temp_min: number;
    temp_max: number;
    pressure: number;
    humidity: number;
  };
  visibility: number;
  wind: { speed: number; deg: number };
  clouds: { all: number };
  dt: number;
  sys: {
    country: string;
    sunrise: number;
    sunset: number;
  };
  timezone: number;
  name: string;
}

选型建议

✓ wttr.in 适用场景

  • 快速原型开发和学习演示
  • 个人项目和小型应用
  • 不需要高可靠性保证
  • 预算有限或不想注册

✓ OpenWeather 适用场景

  • 生产环境需要高可靠性
  • 需要专业级天气数据
  • 需要丰富的天气类型
  • 需要历史数据和预报

安全建议

// ❌ 避免：将 API Key 硬编码在前端
const API_KEY = 'your_secret_key_here';

// ✅ 推荐：使用环境变量
const API_KEY = import.meta.env.VITE_OPENWEATHER_API_KEY;

// ✅ 最佳：通过后端代理转发
// 前端 → 你的后端 → OpenWeather
async function getWeatherProxy(city) {
  const response = await fetch(`/api/weather?city=${city}`);
  return response.json();
}
