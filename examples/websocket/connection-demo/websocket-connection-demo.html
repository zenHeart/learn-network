WebSocket 连接流程交互演示

本页面演示 WebSocket 完整生命周期：握手机制、数据帧格式、心跳保活和重连策略。使用本地服务器 ws://localhost:8080，请先运行 node examples/websocket/handshake/server.js 启动测试服务器。

1. 连接状态

CONNECTING(0)
OPEN(1)
CLOSING(2)
CLOSED(3)

2. 连接流程

1
TCP 三次握手
SYN → SYN-ACK → ACK，建立可靠连接
↓
2
HTTP Upgrade 请求
Connection: Upgrade, Upgrade: websocket, Sec-WebSocket-Key
↓
3
Sec-WebSocket-Key 握手验证
Key + GUID → SHA1 → Base64 = Sec-WebSocket-Accept
↓
4
101 Switching Protocols
协议切换完成，TCP 连接升级为 WebSocket
↓
5
onopen 事件触发
连接已打开，可进行全双工双向通信

6. 常用关闭码

代码名称说明
1000CLOSE_NORMAL正常关闭，双方协商一致
1001CLOSE_GOING_AWAY终端离开（如页面关闭）
1002CLOSE_PROTOCOL_ERROR协议错误
1006CLOSE_ABNORMAL异常关闭（网络中断、非正常断连）
1009CLOSE_TOO_LARGE消息过大
1011CLOSE_UNEXPECTED_CONDITION服务器内部错误
