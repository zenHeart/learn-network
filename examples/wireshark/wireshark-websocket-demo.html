WebSocket 协议基础

WebSocket 是一种在单个 TCP 连接上进行全双工通信的协议。与 HTTP 不同，WebSocket 建立连接后，客户端和服务端可以随时互相发送数据。

WebSocket vs HTTP 对比

维度HTTP/1.1HTTP/2WebSocket
通信方式请求-响应请求-响应全双工
连接短连接多路复用长连接
服务端推送轮询Server Push原生支持
适用场景REST API资源加载实时数据

Wireshark 简介

Wireshark 是功能强大的开源网络协议分析工具，支持实时捕获和离线分析数百种网络协议。

核心功能

  • 实时网络流量捕获
  • 支持多种协议解析（TCP/IP/UDP/HTTP/WebSocket）
  • 强大的过滤器（Capture Filter / Display Filter）
  • 数据包详细信息查看
  • 统计分析和可视化

WebSocket 与 TCP/IP 层级

┌─────────────────────────────────────┐ │ 应用层: WebSocket 数据帧 │ ├─────────────────────────────────────┤ │ 传输层: TCP (可靠连接) │ ├─────────────────────────────────────┤ │ 网络层: IP (路由转发) │ ├─────────────────────────────────────┤ │ 链路层: Ethernet (MAC 地址) │ └─────────────────────────────────────┘ WebSocket 运行在 TCP 之上， 握手阶段使用 HTTP Upgrade 机制。

HTTP Upgrade 请求分析

GET /ws HTTP/1.1
Host: example.com
Connection: Upgrade
Upgrade: websocket
Sec-WebSocket-Version: 13
Sec-WebSocket-Key: dGhlIHNhbXBsZSBub25jZQ==

关键 Header

Header说明
Connection: Upgrade表明需要协议升级
Upgrade: websocket升级为 WebSocket 协议
Sec-WebSocket-Version: 13协议版本，标准为 13
Sec-WebSocket-Key随机 Base64 密钥，用于验证握手

服务端响应

HTTP/1.1 101 Switching Protocols
Connection: Upgrade
Upgrade: websocket
Sec-WebSocket-Accept: s3pPLMBiTxaQ9kYGzzhZRbK+xOo=

状态码 101 表示协议切换成功。

Sec-WebSocket-Accept 计算

过滤器说明

WebSocket 帧结构（RFC 6455）

┌──────────────────────────────────────────────────────┐ │ FIN RSV1 RSV2 RSV3 │ opcode (4bit) │ MASK │ payload │ │ 1bit │ │ 1bit │ len │ ├──────────────────────────────────────────────────────┤ │ Extended payload length (64bit) │ ← 仅当 payload len > 125 ├──────────────────────────────────────────────────────┤ │ Masking-key (32bit) │ ← 仅当 MASK=1 ├──────────────────────────────────────────────────────┤ │ Payload Data │ └──────────────────────────────────────────────────────┘

各字段说明

字段长度说明
FIN1 bit是否为消息最后一帧
opcode4 bits帧类型
MASK1 bit数据是否掩码
Payload len7 bits数据长度
Masking-key32 bits掩码密钥

opcode 帧类型

opcode值说明
0x00继续帧
0x11文本帧
0x22二进制帧
0x88关闭帧
0x99Ping 帧
0xA10Pong 帧

为什么需要掩码？

RFC 6455 规定：客户端发送的数据必须掩码，服务端返回的不需要。

安全原因：防止"缓存污染攻击"

攻击场景： 1. 恶意客户端 → 代理服务器: 发送被掩码的请求 2. 代理服务器: 不理解掩码，不缓存 3. 若不掩码，代理服务器可能缓存恶意内容 掩码后的数据不会被 HTTP 代理服务器缓存。

类型作用时机特点
捕获过滤器 (Capture)抓包时生效BPF 语法
显示过滤器 (Display)抓包后筛选更强大，不丢数据

捕获过滤器 (BPF 语法)

# 基本语法
protocol direction host port

# 示例
tcp port 8080              # 捕获 8080 端口
tcp dst port 8080           # 目标端口
host 192.168.1.1            # 特定 IP
net 192.168.0.0/24         # IP 段
tcp port 8080 and host 127.0.0.1  # 组合

显示过滤器

协议和 WebSocket 过滤

逻辑组合

tcp.port == 8080 and ws.payload.len > 0
http.response.code == 101 or ws.payload.len > 0
